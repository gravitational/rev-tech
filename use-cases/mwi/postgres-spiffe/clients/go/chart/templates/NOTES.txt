Runs a transaction on this schedule ({{ .Values.schedule }}) via CronJob
"{{ include "client.fullname" . }}". Each run spawns its own Job with an
auto-generated name (Kubernetes appends a timestamp-based suffix, not
something this chart controls) -- list them and follow the latest:

  kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} --tail=20 -f

Expected output per run:
  Inserted and committed transaction #<id>: account=wi-demo-go amount=42.00 description="Deposit via Teleport Workload Identity (Go)" created_at=...

To trigger a run right now instead of waiting for the schedule:
  kubectl create job -n {{ .Release.Namespace }} --from=cronjob/{{ include "client.fullname" . }} {{ include "client.fullname" . }}-manual-$(date +%s)
